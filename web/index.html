YOUR 10–15 MINUTE WALKTHROUGH

A demo with a clear story.

Show the change, the automation, the measurements, and the recovery.

  1. Show the working app

    Create a task. Point out the running version and commit.

  2. Show the delivery pipeline

    Push a visible change after connecting GitHub. Open the actual Actions run; explain tests, build, deployment, and readiness checks.

  3. Establish a baseline

    Run normal traffic for at least 30 seconds. Open Grafana and explain request rate and p95 duration.

  4. Introduce a problem

    Run slow or error traffic for two minutes. Observe pending → firing → delivered notification.

  5. Demonstrate recovery

    Switch back to normal traffic. Allow the one-minute query window to clear and show the resolved notification.

  6. Finish with an outage or rollback

    Stop and start the app with the prepared script, or deploy a previously retained release with rollback.ps1.
